# SaaS launch site

**Engagement:** positioning, product marketing site, component library  
**Timeline:** 6 weeks to launch  
**Role:** brand narrative, UX, engineering

---

## Challenge

A venture-backed team needed to launch in a crowded category. The product was
differentiated, but the story read like a feature list—but every competitor claimed
“AI-powered” and “effortless.”

## Approach

We ran a positioning sprint with founders, locked three proof pillars, and mapped
each to a page archetype: problem agitation, proof cluster, ROI framing, and
security assurances. The UI system was built for speed—MDX-backed changelog and
docs patterns for the post-launch team.

## Outcomes

- **Launch-ready narrative** testers could repeat back in usability sessions  
- **Composable landing system** for partner and vertical campaigns  
- **Instrumented funnel** with consent-aware analytics and event taxonomy
